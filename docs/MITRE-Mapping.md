# MITRE ATT&CK Mapping

## Overview

Several Microsoft Sentinel detections created during this lab were mapped to the MITRE ATT&CK framework to better understand attacker behavior.

| MITRE Technique | ID | Lab Activity |
|----------------|----|--------------|
| Brute Force | T1110 | Failed Logons |
| Valid Accounts | T1078 | Successful Logons |
| Command and Scripting Interpreter | T1059 | Process Creation |
| System Information Discovery | T1082 | Process Investigation |

## Purpose

MITRE mapping helps security analysts understand why a detection exists and how it relates to real-world attack techniques.

Using ATT&CK also improves communication between analysts during investigations.
