# Lessons Learned

This project helped me move beyond theoretical knowledge by working directly with Microsoft Sentinel in a practical lab environment.

Throughout the project I learned how Windows Security Events are collected, stored, analyzed, and investigated using Microsoft security technologies.

## Key Takeaways

- Writing KQL queries became easier with practice.
- Event IDs provide valuable investigation context.
- Analytics Rules reduce manual monitoring.
- Documentation is an important part of SOC operations.
- Multiple data sources improve investigation accuracy.
