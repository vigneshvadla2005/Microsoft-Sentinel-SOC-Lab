# Threat Hunting

## Overview

Threat hunting was performed manually using KQL queries within Microsoft Sentinel to investigate Windows Security Events collected from the virtual machine.

The objective was to identify suspicious authentication activity and validate security alerts.

---

## Hunting Activities

The following investigations were completed:

- Failed Logons
- Successful Logons
- Failed Logons by IP Address
- Suspicious IP Investigation
- Process Creation Monitoring
- Event Count Analysis

---

## Hunting Workflow

Collect Events

↓

Run KQL Queries

↓

Analyze Results

↓

Validate Suspicious Activity

↓

Document Findings
