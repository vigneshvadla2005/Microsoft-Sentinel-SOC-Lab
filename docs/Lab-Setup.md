# Microsoft Sentinel Lab Setup

## Objective

Build a cloud-based SOC lab using Microsoft Sentinel for monitoring Windows Security Events and performing threat hunting activities.

---

## Environment

Cloud Platform

- Microsoft Azure

Operating System

- Windows 11 Virtual Machine

Monitoring

- Azure Monitor Agent

SIEM

- Microsoft Sentinel

Log Storage

- Log Analytics Workspace

---

## Security Events Collected

| Event ID | Description |
|----------|-------------|
| 4624 | Successful Logon |
| 4625 | Failed Logon |
| 4688 | Process Creation |

---

## Activities Performed

- Connected Windows VM
- Configured Data Collection Rules
- Verified Log Ingestion
- Wrote KQL Queries
- Created Analytics Rules
- Generated Incidents
- Investigated Alerts
- Documented Findings

---

## Result

The completed lab successfully demonstrated the complete workflow of collecting, detecting, investigating, and documenting Windows security events using Microsoft Sentinel.
