# Incident Response

## Overview

Microsoft Sentinel automatically generates incidents whenever an Analytics Rule detects suspicious activity.

The objective of incident response is to validate alerts, determine the scope of activity, and document investigation findings.

---

## Response Workflow

1. Incident Created
2. Review Alert Details
3. Identify Affected Assets
4. Execute KQL Queries
5. Validate Suspicious Activity
6. Document Findings
7. Close or Escalate

---

## Investigation Activities

During this lab the following activities were performed:

- Authentication review
- Event timeline analysis
- Source IP investigation
- Process monitoring
- Incident documentation

---

## Outcome

Each generated incident was investigated using Microsoft Sentinel and supporting KQL queries to determine whether the detected activity represented suspicious behavior.
